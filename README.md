# 药时记 V1.3.2-beta（V13）

目标设备：Huawei Mate 60 Pro+ / HarmonyOS 7 / 卓易通。

## V13 重点修复

1. **当天任意时间打卡都视为当天已服用。** 例如计划 18:20，08:00 打卡，只要用户确认，连续服用天数会正常增加。
2. **±1 小时确认窗口。** 实际/当前时间与计划时间相差超过 60 分钟时，先提示“当前不在设定服药时间范围”，用户点“仍然打卡”后才写入记录。
3. 超窗确认后仍属于“已服用”，会正常：连续天数 +1、日历状态更新、库存扣减、WebDAV 自动备份。
4. 月统计和日历状态同步修正：提前打卡不会因为“计划时间尚未到”而被忽略。
5. 历史日期手动选择实际服药时间时，同样执行 ±1 小时确认。

## 已验证基线

- 本地 ZIP 备份/恢复：通过真机测试。
- WebDAV 测试连接、备份、列表、恢复：通过。
- 7-4-12 自动备份保留策略：已实现。
- 库存账户/流水、预计耗尽日期：已实现。
- 补签、撤销、短提醒铃声：已实现。
- 卓易通限制：最近任务上滑清除后兼容实例停止，提醒无法由 APK 自恢复；手机重启后建议至少打开药时记一次。

## Windows 离线编译

环境：JDK 17、Android SDK API 35、Build Tools 35.0.0。务必沿用旧版本同一个 `debug.keystore`。

```powershell
$env:JAVA_HOME="F:\jdk17"
$env:Path="$env:JAVA_HOME\bin;$env:Path"
cd F:\yaoshiji
.\build-apk-offline.ps1
```

输出：`YaoShiJi-v1.3.2-beta-debug.apk`

## V13 真机重点测试

- 计划 18:20，08:00 打卡：先弹超窗确认，确认后连续服用天数立即增加。
- 计划 18:20，17:30/19:10 打卡：不弹超窗确认，直接成功。
- 计划 18:20，17:19/19:21 打卡：弹超窗确认。
- 取消确认：不得写入记录、不得扣库存、不得增加连续天数。
- 确认超窗打卡：库存扣减一次；撤销后库存回补。
- 当天唯一一次任务提前确认后，日历应显示完成标识。
